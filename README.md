# unlockCinema

A scalable online movie ticket booking platform built with React, node.js, Epress, MongoDB and redis.

Features :-

Authentication
Movie Management
Theatre Management
City Management
Show Scheduling
Seat Booking
Payment
Reviews
Admin Dashboard

Tech Stack

Fronted

- React
- Vite
- Tailwind
- React Query
- Redux

Backend

- Express
- MongoDB
- Redis

Infrastruture

- Cloudinary
- JWT
- Razorpay
- Paypal

Folder Structure

fronted/
backend/
docs/

Getting Started

npm install
npm run dev (fronted)
npm run start:dev (backend)
